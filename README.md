# 결함 위치 도면 마킹 도구 + 번호 스탬프 카메라 연동

[결함 위치 도면 마킹 도구](https://github.com/yeop9701/defect-location-marker)(2026-10-19, `c26b54c`)를 그대로 가져와,
결함 사진 창에서 [번호 스탬프 카메라](https://github.com/yeop9701/stamp-camera)로 바로 찍을 수 있게 한 **별도 저장소**다.
원래 저장소는 건드리지 않았다.

- 사용 : <https://yeop9701.github.io/defect-marker-stampcam/> (크롬 메뉴 → 앱 설치. 이름 「결함마킹+스탬프」)
- 번호 스탬프 카메라 : <https://yeop9701.github.io/stamp-camera/> (v1.9.0 이상)

## 쓰는 법

결함 카드의 📷(사진 첨부) → 사진 창 아래 줄

| 단추 | 하는 일 |
|---|---|
| **스탬프 촬영 · 다음 0012** | 앱 안에서 카메라가 열린다. 찍을 때마다 ① 스탬프 카메라 설정대로 번호(+메모·날짜)를 찍어 저장(다운로드 폴더 / 스탬프 카메라 목록, 파일이름 규칙도 같음) ② 이 결함에 사진을 붙이고 ③ **첫 장의 번호를 사진번호 칸에 넣는다(칸에 있던 값은 바꾼다)** ④ 번호를 하나 올린다. 닫기 전까지 여러 장 이어서 찍을 수 있다 |
| **기본 카메라 + 번호** | 폰 기본 카메라 앱으로 찍고(화질·초점이 더 나은 기기용), 받은 사진에 번호를 찍어 같은 방식으로 붙인다 |

- **퀵입력 시트에서 바로** (2026-11-17) : 결함을 찍으면 뜨는 퀵입력 시트 위 줄의 **📷 스탬프 촬영 · 0016** 단추로 사진 창을 거치지 않고
  곧바로 촬영 화면이 열린다(사진번호 칸이 있는 결함에만 보인다). 동작은 사진 창의 「스탬프 촬영」과 같고, 촬영 화면을 닫으면
  시트가 그대로 남아 채워진 사진번호가 보인다.
- 촬영 화면 : 다음 번호 · 메모 칸(+「결함 정보로」 = 층수·위치·부재 또는 부재·결함) · 플래시(끔/촬영 때만/계속) · 눌러서 초점 ·
  찍은 장수. Space·Enter·볼륨 단추로도 찍힌다. 가로 화면이면 셔터가 오른쪽.
- **↶ 방금 것 취소** : 방금 찍은 사진을 결함에서 빼고, 스탬프 카메라 목록에서 지우고, 번호를 되돌린다. 그 사진이 사진번호 칸을 채웠으면
  다시 비운다. 여러 번 누르면 차례로 거슬러 간다(촬영 화면을 닫기 전까지). 그 사이 스탬프 카메라 앱 등이 번호를 올렸으면 번호는
  그대로 둔다(겹치지 않게). 다운로드 폴더에 이미 저장된 파일은 브라우저가 지울 수 없어 직접 지워야 한다.
- **촬영 목록** : 셔터 옆 작은 사진을 누르면 스탬프 카메라 목록과 같은 화면이 열린다 — 누르면 크게 보기(다운로드·공유·삭제),
  길게 누르거나 [선택] → 여러 장 다운로드·ZIP·공유·삭제, 전체 ZIP·목록 CSV·전체 삭제. 이번 촬영 화면에서 찍어 결함에 붙인 사진에는
  「결함」 표시가 있고, 지우면 결함에서도 빠진다(그 사진이 채운 사진번호 칸도 비움). 목록에서 지워도 번호는 되돌리지 않는다(스탬프 카메라와 같음).
  목록은 스탬프 카메라 앱과 하나라 여기서 지우면 그쪽에서도 지워진다. 「갤러리 추가」는 결함마킹의 「기본 카메라 + 번호」가 대신한다.
- **다운로드 폴더의 파일은 앱이 지울 수 없다**(브라우저가 막는다). 촬영 목록의 「찍을 때 다운로드 폴더에도 저장」을 끄면
  (= 스탬프 카메라 저장 방식 「앱 목록에만」) 사진이 목록에만 저장되어, 취소·삭제하면 완전히 지워진다. 다 찍은 뒤 ZIP·다운로드로 꺼낸다.
- **점검 앱용 파일이름** : 스탬프 카메라 설정 › 저장 › 파일명 「점검 앱용 : 카메라명+번호 (KIM0012)」 + 카메라명.
  외관조사·3종 체크리스트 앱이 찾는 이름(카메라명 + 번호 4자리)으로 저장되어, 다운로드 폴더를 그대로 그 앱들의 사진 폴더로 쓸 수 있다.
  결함마킹의 사진번호 칸(16)과 외관조사 앱의 「사진번호 16 + 카메라 k」가 같은 파일(KIM0016.jpg)을 가리킨다.
- 사진번호 칸 : 촬영 화면을 열고 **처음 찍은 사진의 번호가 곧바로 들어간다 — 칸에 값이 있어도 바꾼다**(2026-11-17 사용자 요청).
  같은 촬영 화면의 두 번째 장부터는 첫 장 번호 그대로. 「방금 것 취소」로 첫 장을 취소하면 원래 값으로 되돌리고 다음 장이 다시 번호를 넣는다.
  퀵입력 시트가 열려 있으면 그 칸도 바로 바뀐다. 실행취소(Ctrl+Z)로도 되돌릴 수 있다.
- 기존의 「앨범에서 선택」「촬영」「사진 촬영」은 그대로 있다(번호를 찍지 않는 예전 방식).

## 손글씨 입력 (2026-11-17)

S펜으로 칸에 바로 쓰는 기능. 삼성 키보드 필기 인식이 잘 안 맞고, 칸이 작고, 칸마다 눌러야 하는 불편 때문에 만들었다.

- **켜고 끄기** : 설정(⚙) › 「손글씨 입력: 켬/끔」 (기본 켬). 켜면 태블릿 모드의 퀵입력 시트가 **칸마다 큰 필기 상자**가 된다.
  외관 결함은 폭·길이·개수·사진# 4칸이 필기 상자, 부재·자재·결함은 누르는 단추다(아래 「연결 목록」 — 목록에 없는 말만 ✎ 로 손글씨).
- **숫자 칸**(폭·길이·개수·사진#·측정값·경간·도분초…) : 앱 안의 작은 숫자 인식기로 **인터넷 없이** 그 자리에서 숫자로 읽는다.
  아래쪽 작은 점은 소수점. 틀리면 상자 아래 칸에 직접 고치거나 ✕ 로 지우고 다시 쓴다. 자신 없게 읽은 것은 「확인 필요」.
- **글자 칸**(부재·자재·결함·층수·위치…) : 현장에서는 **쓴 글씨를 그대로 저장**한다(「변환 대기」). 결함 목록 카드에도 글씨 그림이 보인다.
  ▼ 로 목록에서 고를 수도 있다.
- **글자로 바꾸기** : 인터넷이 되면 자동으로, 또는 설정 › 「손글씨 변환…」 창에서 한꺼번에. 원본 글씨와 바뀐 글자를 나란히 보여 주고,
  틀린 것은 그 자리에서 고치거나 후보 단추를 누른다.
  - 엔진 둘 중 고름 : **구글 필기 인식**(무료 · 공식 공개 API 가 아니라 언젠가 막힐 수 있음 · 글씨가 구글로 감) /
    **Claude**(`claude-opus-5-5`, 점검 용어와 이 현장에서 쓴 말을 같이 알려 줌 · API 키 필요 · 키는 그 브라우저에만 저장)
  - 인터넷 오류면 「변환 대기」 그대로 두었다가 다음에 다시 한다.
- **원본 글씨는 지우지 않는다** — 변환한 뒤에도, 직접 고친 뒤에도 남는다(프로젝트 파일·자동저장에 같이 실림, 마커의 `ink`).
- 시트의 ◀ 앞 / 다음 ▶ 로 찍어 둔 결함을 차례로 넘기며 채운다. 떠 있는 줄의 ✎ 는 고른(없으면 마지막) 결함의 필기 상자를 열고,
  변환 대기 칸 수를 보여 준다.
- 값 이어받기 : 분류 칸이 아직 글씨면 글씨째 다음 결함으로 물려준다(같은 글씨는 변환할 때 한 번만 보낸다). 실측값은 물려주지 않는다.
- CSV·엑셀로 내보낼 때 아직 글자가 아닌 칸이 있으면 알려 준다(그 칸은 빈칸으로 나간다).
- S펜을 한 번 쓰면 그 뒤 손가락·손바닥 터치는 필기 상자에서 무시한다.

파일 :

```

ink/digits-model.js          숫자 인식 모델 (작은 CNN, int8, 약 60KB). 직접 고치지 않는다

tests/test-ink.mjs           손글씨 검사 (구글·Claude 는 가짜 응답, LIVE=1 이면 구글에 실제로 한 번)
```

## 부재 → 자재 → 결함 연결 목록 (2026-11-17)

부재·자재·결함 선택 목록을 엑셀 `taxonomy/부재_자재_결함.xlsx`(원본 : 참고/부재_자재_결함_최종.xlsx)로 바꿨다.
부재 21 · 자재 37 · 결함 43, 부재-자재 조합 98.

- **부재를 고르면 그 부재에 쓰이는 자재만**, **부재·자재를 고르면 그 조합에 생기는 결함만** 목록에 나온다.
  예 : 벽체 → 자재 15개 / 벽체·콘크리트 → 결함 21개. 순서는 엑셀 그대로(ㄱㄴㄷ, 자재는 마감재가 맨 끝).
- 앞 칸이 비었거나 엑셀에 없는 말이면 넓게 보여 준다 : 부재만 → 그 부재의 모든 자재 결함 / 자재만 → 그 자재가 쓰인
  모든 부재의 결함 / 둘 다 없음 → 전체.
- **결함은 여러 개** — 한 칸에 `/` 로 잇는다(예 : `균열/백태`). 통계의 결함별 개수는 `/` 로 나눠 각각 센다.
  파일이름에 들어갈 때는 `_` 로 바뀐다(`/` 는 파일이름에 못 씀).
- **퀵입력 시트**(태블릿) : 참고/결함선택_예시.html 처럼 누르는 단추. 한 번에 한 줄만 펼친다 —
  부재를 누르면 접히고 자재 줄이, 자재를 누르면 결함 줄이 펼쳐진다. 접힌 줄을 누르면 다시 펼쳐 바꾼다.
  결함 단추는 누를 때마다 넣고 뺀다. 아래에 `→ 벽체 콘크리트 균열/백태` 로 합친 결과가 보인다.
  - 부재를 바꾸면 새 부재에 없는 엑셀 자재·결함은 비운다(엑셀에 없는 직접 쓴 말은 둔다).
  - 줄 끝 **✎** : 목록에 없는 말 — 손글씨 켬이면 그 칸 필기 상자가 열리고, 끔이면 입력칸이 된다.
    이어받은 손글씨가 아직 글자가 아니면 필기 상자가 저절로 열린다.
  - 손글씨 켬이어도 부재·자재·결함은 단추, 폭·길이·개수·사진# 은 필기 상자.
- **결함 목록 카드·표로 입력의 ▼** : 같은 줄의 부재·자재에 맞춰 걸러 보여 준다. 결함 ▼ 는 여러 개를 고르는 동안 열려 있고
  (누르면 넣고 다시 누르면 뺀다), ▼ 를 한 번 더 누르거나 바깥을 누르면 닫힌다. 칸에 그냥 쳐 넣는 것은 그대로 된다.
- **목록수정** 창 = 엑셀에 없는 말을 더 붙이는 자리(기본은 빈칸). 여기 말과 손으로 친 새 말은 **엑셀에 없는 것만** 목록 끝에
  붙는다 — 엑셀에 있는 말까지 붙이면 걸러 낸 목록이 도로 넓어지기 때문. 예전에 저장해 둔 목록도 같은 규칙.

엑셀을 고친 뒤에는 :

```
python taxonomy/build_taxonomy.py taxonomy/부재_자재_결함.xlsx taxonomy/defect-taxonomy.js
```

(목록 시트에 없는 이름이 조합 시트에 있으면 만들지 않고 알려 준다.) 그다음 service-worker.js 의 CACHE_VERSION 을 올린다.

## 결함 정보(ⓘ) · 내보내기 (2026-11-18)

- **ⓘ** : 결함 카드의 카메라와 ✕ 사이. 그 결함에 손으로 쓴 글씨(칸 이름·원본 그림·바뀐 글자)와 카메라 메모(사진·번호·메모·시각)를 한 창에서 본다.
  메모는 찍을 때 `m.photoMeta` 에 사진 내용 열쇠로 적는다. 이 기능 전에 찍은 사진은 「메모 기록 없음」.
- **태블릿 그리기 작업바** : 하단 바 하나에 도구 7개·색·굵기·⚙·모눈·모두 지움. 도구별 설정(선 지우개 굵기·글상자·모눈 칸)은 ⚙, 폭 1240px 미만은 색·굵기를 단추 하나씩으로 접는다.
- **CSV** : 결함 한 건이 한 줄, 글자 값만(손글씨 그림은 못 넣는다). 아직 글자로 안 바뀐 칸은 빈칸.
- **엑셀** : 조사 종류별 시트 + 손글씨가 있으면 **「손글씨」 시트**(결함 한 줄, 제목별 칸에 글씨 그림과 바뀐 글자).
- **사진 ZIP** : `번호_고유번호_층수_위치_부재_자재_결함`.
- **표로 입력** : 유형·X·Y·각도·배율·층수·위치·부재·자재·결함·폭·길이·개수·사진번호·비고. 예전 9칸 양식을 유형 칸부터 붙여도 제자리에 들어간다.

## 번호가 이어지는 원리

두 앱이 같은 주소(`yeop9701.github.io`) 아래에 있으면 브라우저가 저장 공간을 같이 쓴다.

- 번호·메모·저장 방식 = 스탬프 카메라 설정 `localStorage['stampcam.settings.v1']` — 찍을 때마다 새로 읽고, 올린 번호를 곧바로 써 둔다
- 촬영 목록 = 스탬프 카메라 IndexedDB `stampcam / shots` — 결함마킹에서 찍은 사진도 스탬프 카메라 목록·ZIP 에 나온다
- 스탬프 카메라 **v1.8.0** 부터는 다시 볼 때(또는 다른 탭에서 바뀌는 즉시) 번호·메모를 새로 읽는다. 그 전 판은 뒤에 떠 있다가
  옛 번호로 찍어 번호가 겹칠 수 있다

그래서 **파일로 열거나(file://) 다른 주소에 올리면** 번호는 그 주소 안에서만 이어진다(동작 자체는 된다).

스탬프 카메라 설정의 저장 방식이 「공유」면, 찍을 때마다 공유 창이 떠서 결함 기록이 끊기므로 스탬프 카메라 목록에만 저장한다.
